# Mandarin multi-word constructions: the patterns. Hand-curated — not generated
# by dictgen.
#
# Format: one pattern per line, `#` comments ignored; what each one means is in
# `phrases.<meta>.txt`, joined on the pattern. A slot matches one segmenter
# token, so a pattern is written in the pieces the segmenter actually cuts:
# `打 * 喷嚏`, not `打 * 喷 嚏`, and a construction the segmenter already takes
# whole (看不起, 舍不得) is a headword, not a phrase. `*` is a gap of up to four
# tokens and may cross a comma; `?` is a gap of one and may not.
#
# ## What belongs here
#
# Only what the segmenter cannot see because it is split, and whose parts
# mislead read one by one:
#
# - Separable verbs with something inside (`帮了我一个忙` is 帮忙): `帮 * 忙`.
# - Correlative frames (`越 * 越`, `连 * 都`, `不是 * 而是`) and the verb-
#   specific `一 V * 就` lines — bare `一 * 就` was mostly a numeral and a noun.
# - A-not-A questions the segmenter splits (`知 不 知道`).
# - Sequences the segmenter cuts into a misleading word: 回过头 is 回 + 过头
#   "to overdo it", so `回 过头` is here to say what it means.
#
# **Chengyu are not here.** An unbroken four-character idiom is a headword
# tagged `idiom` in lex.txt: only a headword gets a band, a status and a row in
# the words table.
#
# Each pattern was proposed by a model on 2026-09-23, measured with
# `measure:phrase-fit` over fiction and OPUS, and kept at 8 hits or more with
# its sampled sentences read. A single-character slot is the danger: 操 * 心
# caught 曹操，心说 and 点 * 头 caught 四点，日头, and both were dropped.
