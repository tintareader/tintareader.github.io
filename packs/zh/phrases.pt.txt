# What each Mandarin construction in `phrases.txt` means, in Brazilian Portuguese.
#
# Format: pattern|gloss — joined to `phrases.txt` on the pattern. A pattern
# this file does not explain falls back to `phrases.en.txt`, so a translation
# in progress shows Portuguese where it has one and English elsewhere.
#
# Hand-written, like `phrases.txt` and `phrases.en.txt` — dictgen does not
# generate this file, it only carries it across into the manifest.
#
# Two rules, both inherited from the file this translates:
#
#   - The patterns on the left are the join key and must not change. A changed
#     pattern is a phrase the app stops finding; an invented one is a phrase it
#     hunts for and never finds.
#   - The sense count must match `phrases.en.txt`. `;` separates senses and
#     `,` joins near-synonyms inside one, exactly as in `gloss.pt.txt`.
#
# Verbs are glossed in the infinitive. The Chinese inside a gloss — the split
# form (帮了我一个忙), the frame (生X的气), the word it is not (过世) — is
# kept exactly as `phrases.en.txt` has it: it is Mandarin the reader is
# studying, not English prose.
# ---- Separable verbs (离合词) split by 了/过/个/a pronoun or a possessive: the
# contiguous form is usually one headword and then never matches two slots; where it
# is not (请假, 照相, 理发), the pattern also underlines the adjacent pair.
