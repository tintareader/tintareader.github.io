# What each English phrase in `phrases.txt` means, in Mandarin Chinese.
#
# Format: pattern|gloss — joined to `phrases.txt` on the pattern. A pattern
# this file does not explain falls back to `phrases.en.txt`, so a translation
# in progress shows Chinese where it has one and English elsewhere.
#
# Hand-written, like `phrases.txt` and `phrases.en.txt` — dictgen does not
# generate this file, it only carries it across into the manifest.
#
# Three rules, all inherited from the file this translates:
#
#   - The patterns on the left are the join key and must not change. A changed
#     pattern is a phrase the app stops finding; an invented one is a phrase it
#     hunts for and never finds.
#   - The sense count must match `phrases.en.txt`. `;` separates senses and
#     `,` joins near-synonyms inside one, exactly as in `gloss.zh.txt`.
#   - `;` `( )` and `: ` are ASCII, never their fullwidth forms: the app scans
#     for those exact characters to find where one sense ends and the next
#     begins.
#
# Verbs are glossed as bare Chinese verbs — the English `to` has no counterpart
# to carry across.
