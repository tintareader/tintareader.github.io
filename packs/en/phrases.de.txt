# Was jede englische Wendung in `phrases.txt` bedeutet, auf Deutsch.
#
# Format: pattern|gloss — verbunden mit `phrases.txt` über das Muster. Ein
# Muster, das diese Datei nicht erklärt, fällt auf `phrases.en.txt` zurück:
# eine Übersetzung in Arbeit zeigt Deutsch, wo es schon eines gibt, und sonst
# Englisch.
#
# Von Hand geschrieben, wie `phrases.txt` und `phrases.en.txt` — dictgen
# erzeugt diese Datei nicht, sondern übernimmt sie nur in das Manifest.
#
# Zwei Regeln, beide von der Datei geerbt, die hier übersetzt wird:
#
#   - Die Muster links sind der Verbindungsschlüssel und dürfen sich nicht
#     ändern. Ein geändertes Muster ist eine Wendung, die die App nicht mehr
#     findet; ein erfundenes eine, nach der sie sucht und nie fündig wird.
#   - Die Zahl der Bedeutungen muss mit `phrases.en.txt` übereinstimmen. `;`
#     trennt Bedeutungen, `,` verbindet Beinahe-Synonyme innerhalb einer
#     Bedeutung, genau wie in `gloss.de.txt`.
#
# Verben stehen als Infinitiv ohne `zu`. Das Deutsche hat einen Infinitiv, wo
# das Englische `to go` hat, also genügt das Verb allein und braucht keine
# eigene Markierung.
