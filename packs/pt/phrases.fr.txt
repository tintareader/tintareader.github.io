# What each Portuguese phrase in `phrases.txt` means, in French.
#
# Format: pattern|gloss — joined to `phrases.txt` on the pattern. A pattern
# this file does not explain falls back to `phrases.en.txt`, so a translation
# in progress shows French where it has one and English elsewhere.
#
# Hand-written, like `phrases.txt` and `phrases.en.txt` — dictgen does not
# generate this file, it only carries it across into the manifest.
#
# Two rules, both inherited from the file this translates:
#
#   - The patterns on the left are the join key and must not change. A changed
#     pattern is a phrase the app stops finding; an invented one is a phrase it
#     hunts for and never finds.
#   - The sense count must match `phrases.en.txt`. `;` separates senses and
#     `,` joins near-synonyms inside one, exactly as in `gloss.fr.txt`.
#
# Verbs are glossed as French infinitives. Many of these phrases look like
# French and are not: `dar certo` is not « donner certain », `fazer questão`
# is « tenir à », not « faire question », `de repente` can mean « peut-être »,
# `tomar conta` is looking after, not « prendre compte ». The gloss says what
# the Portuguese means, and marks register (vulgaire, familier) as the English
# file does.
