# Arabic multi-word expressions: the patterns. Hand-curated — not generated
# by dictgen.
#
# Format: one pattern per line, `#` comments ignored. What each one means is in
# `phrases.<meta>.txt`, joined on the pattern.
#
# A slot matches one token's root, its normalised surface (marks stripped), or
# its `from`, and **an Arabic token is the whole written word**: `بالإضافة إلى`
# is two slots, and `لسوء` in `لسوء الحظ` is one token whose root is `سوء`, so
# `سوء الحظ` already covers it. A slot written as a verb's citation form
# (`حصل على`) catches every form the lemma table folds to it (`حصلت على`,
# `يحصل على`); one written as the text writes it (`على ما يرام`) is matched
# as written. A careless spelling that the fold does not send to the same
# root is a pattern of its own (`بالاضافة إلى`).
#
# ## What belongs here
#
# Only phrases whose parts mislead read one by one: `على ما يرام` is not "on
# what is intended", `حصل على` is not "happened on", `ابن السبيل` is not "son
# of the road". Transparent ones (`لا أعرف`, `في الصباح`, `الأسبوع الماضي`,
# since the adjective rule in `languages/ar/cues.ts` reads `الماضي` as "last")
# were measured and left out. So were `فكر في`, `ابتعد عن`: the preposition
# cues already give `في` "about" and `عن` "from" there.
#
# Each pattern was proposed on 2026-09-29 and measured with `measure:phrase-fit
# -- --lang ar --corpus opus,tanzil` over the whole OPUS sample (2.27M lines)
# and the Tanzil text, which is counted and never copied. Most were kept at
# eight hits or more in either. A few formulas every speaker uses are kept
# below that, because a film subtitle is the wrong place to meet them
# (`جزاك الله خيرا`, `لا حول ولا قوة إلا بالله`, `إنا لله وإنا إليه راجعون`,
# `البقاء لله`, `رضي الله عنه`): the matcher was checked to find each.
