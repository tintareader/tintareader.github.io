# Tinta — Arabic letters table, for letters mode.
# This project's own work, derived from no third-party source: unencumbered.
# What each letter sounds like is said per reader, in letters.<meta>.txt.
#
# key|group|name|name_plain|rom|rom_plain|ipa|example|flags
#   key      the unit, lower case; a word is cut into these longest first
#   group    letter (the alphabet), pair (letters read as one), also (beyond the alphabet)
#   name     the letter's name in Arabic (scholarly), name_plain (plain)
#   rom      romanisation (scholarly, ALA-LC), rom_plain (plain)
#   ipa      its usual sound, for the grid
#   example  a common word with it, as the dictionary keys it
#   flags    vowel; front (a vowel that softens c and g before it: e, i, y); start (a pair only at the head of a word);
#            closed (a pair refused before a vowel or a doubled letter); end (only at the tail);
#            heavy (an emphatic consonant)
#
# The 28 letters in their dictionary order, then the shapes the alphabet adds:
# hamzah on its own and on its three seats, alif with maddah, tāʾ marbūṭah and
# alif maqṣūrah. Each is keyed by its bare form; which of its four joined shapes
# a word writes it in is worked out by the engine, from Unicode's joining types,
# and is not stored here.
#
# Two romanisations, both kept, and the reader picks in Settings: `rom` is the
# scholarly one (ALA-LC: ā, ḥ, ʻ, ʼ) and `rom_plain` the everyday one (aa, h,
# '). The plain one does not mark the heavy letters: capitals (H, S, D, T, Z)
# were tried and dropped on 2026-10-01, because a capital also starts a name or
# a sentence, and the letter itself, beside it on every tile, already tells ح
# from ه. The scholarly one is for whoever wants the difference in Latin.
