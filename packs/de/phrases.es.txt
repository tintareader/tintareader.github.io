# What each German phrase in `phrases.txt` means, in Spanish.
#
# Format: pattern|gloss — joined to `phrases.txt` on the pattern. A pattern
# this file does not explain falls back to `phrases.en.txt`. Hand-written,
# like the two files it translates; dictgen only carries it into the manifest
# (`register --file phrases.es`). The patterns must not change and the sense
# count must match `phrases.en.txt`.
