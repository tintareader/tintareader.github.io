# German multi-word expressions: the patterns. Hand-curated — not generated
# by dictgen.
#
# Format: one pattern per line, `#` comments ignored. What each one *means* is
# in `phrases.<meta>.txt`, joined on the pattern (case-blind) — the same split
# `lex.txt` and `gloss.<meta>.txt` make. Which phrases exist is a fact about
# German; what they mean is a fact about a pair of languages.
#
# A slot matches a token's root, its surface or its `from`, so a pattern whose
# head inflects is written in the citation form: `Angst haben` catches *habe
# Angst*, *hatte Angst*, *Angst gehabt*. The verb-second order (*hat Angst*,
# *gibt es*) is not written here: the German provider's `keyForms` writes it
# for every pattern whose last slot is a verb, and for every pattern led by
# `es` (engine README, "Constructions"). `*` is a gap of up to four words, for
# the frames German builds around another word — `um … zu`, `weder … noch`.
#
# Written as candidates (2026-09-29), then kept only where `measure:phrase-fit
# -- --lang de --corpus fiction,opus` found three or more hits over 1.9M words
# of Tatoeba and five Gutenberg novels, and the sampled surfaces were read
# (tools/dictgen/README.md, "German phrases"). No frequency data ships with
# them and nothing here is copied from a corpus, so the file is unencumbered.
#
# Only phrases where the word-by-word reading misleads, as for the other packs:
# `ein paar` is "a few", not "a pair"; `nicht mehr` is "no longer". `jeden Tag`,
# `wie lange`, `seit Jahren` fired often and were cut, because the reader
# decodes them without help.
