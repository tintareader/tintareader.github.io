# Tinta — German letters table, for letters mode.
# This project's own work, derived from no third-party source: unencumbered.
# What each letter sounds like is said per reader, in letters.<meta>.txt.
#
# key|group|name|name_plain|rom|rom_plain|ipa|example|flags
#   key      the unit, lower case; a word is cut into these longest first
#   group    letter (the alphabet), pair (letters read as one), also (beyond the alphabet)
#   name     the letter's name in German
#   ipa      its usual sound, for the grid
#   example  a common word with it, as the dictionary keys it
#   flags    vowel; front (a vowel that softens c and g before it: e, i, y); start (a pair only at the head of a word);
#            closed (a pair refused before a vowel or a doubled letter); end (only at the tail)
#
# The pairs are kept to the ones German spelling treats as one sound without
# exception worth a learner's while: sch, ch, ck, chs, ei, ie, au, eu, äu, and st
# and sp at the start of a word, where they say "sht" and "shp". `chs` collapses
# the whole cluster to ks (sechs, wachsen) rather than ch's own sound plus a
# separate s. Anything subtler is for the notes, which say "usually" — the
# common -ig ending (König, zwanzig) is one such note on g, not a cut of its
# own, since ig elsewhere (Igel) is plain i+g.
