# What each French phrase in `phrases.txt` means, in Spanish.
#
# Format: pattern|gloss — joined to `phrases.txt` on the pattern. A pattern
# this file does not explain falls back to `phrases.en.txt`, so a translation
# in progress shows Spanish where it has one and English elsewhere.
#
# Hand-written, like `phrases.txt` and `phrases.en.txt` — dictgen does not
# generate this file, it only carries it across into the manifest.
#
# Two rules, both inherited from the file this translates:
#
#   - The patterns on the left are the join key — elision spacing included —
#     and must not change. A changed pattern is a phrase the app stops
#     finding; an invented one is a phrase it hunts for and never finds.
#   - The sense count must match `phrases.en.txt`. `;` separates senses and
#     `,` joins near-synonyms inside one, exactly as in `gloss.es.txt`.
#
# Verbs are glossed as Spanish infinitives — the English `to` in the file
# this translates is English citation form and has no counterpart to carry
# across. Register marks are written as Spanish does: (coloq.), (vulgar), (argot).
