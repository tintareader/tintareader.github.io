# Tinta — French letters table, for letters mode.
# This project's own work, derived from no third-party source: unencumbered.
# What each letter sounds like is said per reader, in letters.<meta>.txt.
#
# key|group|name|name_plain|rom|rom_plain|ipa|example|flags|sounds
#   key      the unit, lower case; a word is cut into these longest first
#   group    letter (the alphabet), pair (letters read as one), also (beyond the alphabet)
#   name     the letter's name in French
#   rom      romanisation (empty for a Latin alphabet)
#   ipa      its usual sound, for the grid
#   example  a common word with it, as the dictionary keys it
#   flags    vowel; front (a vowel that softens c and g before it: e, i, y); start (a pair only at the head of a word);
#            closed (a pair refused before a vowel or a doubled letter); end (only at the tail);
#            heavy (an emphatic consonant)
#   sounds   a pair's number of sounds where it is the same in every word; empty where it
#            changes with the word (the card then says only that the letters are read together)
#
# French spells one sound with several letters more often than any other pack
# here, so it has the most pairs. The nasal vowels (on, an, en, in, ain, ein, oin)
# are pairs only before a consonant or at the end of a word: `bon` is nasal and
# `bonne` and `bone` are not, which is what the `closed` flag says. `ez` is a pair
# only at the end of a word (chez, parlez). `tion` (nation, addition) reads
# sjɔ̃, not the plain t a letter-by-letter cut would give it; its own `after:s`
# note says why `question` keeps a plain t instead. Everything subtler — the
# silent final consonants, `ent` in a verb — is for the notes.
