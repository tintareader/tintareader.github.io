# Indonesian multi-word expressions: the patterns. Hand-curated — not generated
# by dictgen.
#
# Format: one pattern per line, `#` comments ignored. What each one *means* is
# in `phrases.<meta>.txt`, joined on the pattern — the same split `lex.txt` and
# `gloss.<meta>.txt` make, for the same reason.
#
# A pattern is a sequence of slots matched against consecutive tokens. Each
# slot matches a token's **root** (after the stemmer) or its lower-cased
# surface, so `angkat kaki` also catches `mengangkat kaki` and an invariant
# formula is written just as it is read (`apa boleh buat`). `*` is a gap of up
# to four tokens, for the correlative frames (`baik * maupun`).
#
# ## A phrase, a headword or a key
#
# Indonesian has three places for a multi-word meaning, and each expression
# goes in exactly one:
#
#   - **A headword** (`lex.txt`) when the words make a new word: `rumah sakit`,
#     `kambing hitam`. The tokeniser glues it into one token and it is counted
#     and learned as one item.
#   - **A key** (`expression: meaning` inside a gloss) when the expression pins
#     one sense of one word: `minta maaf: to apologize` on `minta`.
#   - **A phrase** (here) when the reader should be told what the words mean
#     together without losing them as words: `apa boleh buat`, `mau tidak
#     mau`, `angkat tangan`. It underlines and adds a line to the card; every
#     word keeps its own entry, band and count.
#
# A test holds the line: no pattern here is a headword or a key the pack
# already states. A pattern may *contain* a glued headword (`tidak tahu terima
# kasih`) — the provider's `keyForms` joins those slots the way the tokeniser
# does.
#
# ## What belongs here
#
# Only expressions where the word-by-word reading misleads. `dari hari ke hari`
# is not here: "from day to day" already teaches it. Where a literal reading is
# live as well, the gloss carries both, and the commoner reading first — `buka
# mata` is mostly someone opening their eyes.
#
# Every pattern was measured with `measure:phrase-fit` over the fiction and
# OpenSubtitles samples, cut at about one per million words in either, and the
# words each one caught were read: 22 were dropped because the stemmer let them
# catch something else (`pasang mata` caught *sepasang mata* "a pair of eyes",
# `tidak apa` caught *tidak berapa*). There is no frequency data in this file,
# so a phrase carries no band. See "Phrases for Indonesian" in
# tools/dictgen/README.md, and NOTICE at the repo root.
