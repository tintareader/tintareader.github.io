# Spanish multi-word expressions: the patterns. Hand-curated — not generated
# by dictgen.
#
# Format: one pattern per line, `#` comments ignored. What each one *means* is
# in `phrases.<meta>.txt`, joined on the pattern — the same split `lex.txt` and
# `gloss.<meta>.txt` make, for the same reason. Which phrases exist is a fact
# about Spanish; what they mean is a fact about a pair of languages.
#
# A pattern is a sequence of slots matched against consecutive tokens. Each
# slot matches a token's **root** or its normalised surface, so a pattern whose
# head inflects is written in the citation form (`tener que` catches `tengo
# que`, `tenía que`, `tendremos que`) and an invariant phrase is written just
# as it is read (`sin embargo`). `*` is a gap of up to four tokens, for
# constructions written around another word; Spanish needs none so far.
#
# There is no frequency data behind these — the rank list is unigram — which is
# why a phrase carries no band and never enters the band histogram. See NOTICE
# at the repo root.
#
# ## What belongs here
#
# Only phrases where the word-by-word reading misleads. `fin de semana` is not
# here: "end of week" already teaches it, and an underline over a phrase the
# reader can decode is noise that makes the ones that matter easier to ignore.
# Transparent multi-word prepositions (`antes de`, `cerca de`, `delante de`)
# are out for the same reason.
#
# Where a pattern has a live literal reading as well as its idiomatic one
# (`ir a` before a noun is plain motion; `tratar de` can mean "to be about"),
# the gloss carries both senses rather than the phrase being dropped. A gloss
# that shows the reader the choice is more use than silence.
