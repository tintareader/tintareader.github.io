# What each Spanish phrase in `phrases.txt` means, in (Brazilian) Portuguese.
#
# Format: pattern|gloss — joined to `phrases.txt` on the pattern. A pattern
# this file does not explain falls back to `phrases.en.txt`, so a translation
# in progress shows Portuguese where it has one and English elsewhere.
#
# Hand-written, like `phrases.txt` and `phrases.en.txt` — dictgen does not
# generate this file, it only carries it across into the manifest.
#
# Two rules, both inherited from the file this translates:
#
#   - The patterns on the left are the join key and must not change. A
#     changed pattern is a phrase the app stops finding; an invented one is a
#     phrase it hunts for and never finds.
#   - The sense count must match `phrases.en.txt`. `;` separates senses and
#     `,` joins near-synonyms inside one, exactly as in `gloss.pt.txt`.
#
# Verbs are glossed as bare Portuguese infinitives — the English `to` in the
# file this translates is English citation form and has no counterpart to
# carry across. Spanish inside brackets, and a Spanish key before `: `, stay
# Spanish. The Portuguese is Brazilian; a European form is noted only where
# the difference would confuse. Spanish and Portuguese share many phrases,
# and some that look shared are false friends: where a Portuguese reader
# would assume the cognate, the gloss says what the Spanish means and may
# add `(≠ port. "...")`.
